# Car Rental Detail Card

A clean, modern, and interactive car rental detail and pricing card built using pure HTML and CSS. 

This project was developed specifically to master fundamental CSS layout techniques without relying on modern layout modules like Flexbox or Grid. The primary focus of this project is mastering the **CSS Box Model** and the **`position` property** (`relative` and `absolute`).

## 🎯 Learning Objectives & Focus Areas

*   **Absolute & Relative Positioning:** The "Special Offer" badge is precisely placed over the car image by establishing a positioning context (`position: relative` on the container and `position: absolute` on the badge).
*   **Inline-Block Layouts:** Managing horizontal alignments and spacing using `display: inline-block` for lists and buttons.
*   **CSS Box Model:** Deep dive into `margin`, `padding`, `border`, and dealing with dimensional properties like `min-height` and `max-width`.
*   **Advanced Selectors:** Utilizing pseudo-classes like `&:last-child` and `&:nth-child()` for targeted table styling.
*   **Interactive States:** Creating engaging UI feedback using `:hover` and `outline` properties on call-to-action buttons.

## 🚀 Features

*   **Responsive Image Container:** Adapts to the parent container's width.
*   **Positioned Badges:** Custom "Special Offer" tag overlapping the image.
*   **Feature List:** Icon-integrated horizontal list displaying car specifications.
*   **Pricing Table:** A clean, easy-to-read data table highlighting discount prices.
*   **Hover Effects:** Prominent "Rent Now" button with outline animations on hover.

## 🛠️ Technologies Used

*   **HTML5:** Semantic document structure.
*   **CSS3:** Custom styling, positioning, and hover effects.
*   **Google Fonts:** Typography styling (Quattrocento Sans).
*   **FontAwesome:** Vector icons for car features.
